Firebase Firestore Security Rules

These are the database access rules for the KJBM MINDS website. Copy them and publish them in Firebase Console.

Important: This dashboard can display and copy rules. It cannot deploy them to Firebase automatically. After copying, open Firebase Console → Firestore Database → Rules, replace the existing rules and click Publish. 


How to publish


    

  1. Copy the rules using the button above.
    2. 

  2. Open your Firebase project: kjbm-minds.
    3. 

  3. Open Firestore Database.
    4. 

  4. Select the Rules tab.
    5. 

  5. Replace the rules with the copied text.
    6. 

  6. Press Publish.
